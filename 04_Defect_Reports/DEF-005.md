## Steps to reproduce

1. Create a booking, mark it **SEATED** (and optionally **COMPLETED**).
2. Call `DELETE /api/reservations/{id}` (or PATCH status CANCELLED).

**Test data:** Reservation in SEATED / COMPLETED state

## Expected result

409 – *Cannot change status from SEATED/COMPLETED to CANCELLED*; status unchanged.

## Actual result

Status changes to **CANCELLED** (and a refund could be calculated) for a guest who already ate.

## Evidence

Cycle 1 log: TC-ST-08 *Actual: Allowed: status is now CANCELLED*; Newman PM-12 got 200 instead of 409.
