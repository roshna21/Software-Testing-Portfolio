## Steps to reproduce

1. With today = 16 Nov 2026, book for **17 Dec 2026** (today + 31).

**Test data:** date = 2026-12-17

## Expected result

Rejected – *Bookings open only 30 days in advance*.

## Actual result

Accepted.

## Evidence

Cycle 1 log: TC-BVA-22 *Actual: Accepted*.

## Root cause

Check was `booking_date > today + timedelta(days=MAX_DAYS_AHEAD + 1)` – the extra `+ 1` moved the boundary by a day.

## Fix

Removed the `+ 1`.  
File: `application/reservation_system/validators.py` · Fixed in build **v1.1.0** · Commit `2125088`

## Retest (Cycle 2)

Re-ran TC-BVA-22 on build v1.1.0 – **all passed**. Full regression (127 test cases + 31 Postman assertions) also passed, so the fix did not break anything else. Status changed to **Closed**.
