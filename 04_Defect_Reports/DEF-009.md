## Steps to reproduce

1. Book a table.
2. Open **Staff view** for that date.

**Test data:** Any reservation

## Expected result

Table rows have a continuous bottom border; action buttons sit inside the cell.

## Actual result

The Actions cell is narrower than its column and its bottom border stops short of the others.

## Evidence

Screenshot `07_Screenshots/selenium/cycle1_TC-UI-06a_staff_seated.png` (found while reviewing evidence, not by an automated assertion).

## Root cause

The `<td class="actions">` was given `display: flex`, which stops it behaving as a table cell.

## Fix

Moved the flex layout to an inner `<div class="actions">` inside the cell.  
File: `application/reservation_system/templates/reservations.html` · Fixed in build **v1.1.0** · Commit `510abe1`

## Retest (Cycle 2)

Re-checked the staff view in screenshot `07_Screenshots/selenium/cycle2_TC-UI-06a_staff_seated.png` – row border is now continuous. Full regression passed. Status changed to **Closed**.
