# DEF-006: Names made only of spaces (or one letter padded with spaces) are accepted

## Steps to reproduce

1. Enter name `"    "` (four spaces) or `" A "`.
2. Submit a valid booking.

**Test data:** customer_name = "    " / " A "

## Expected result

Rejected – name must be 2–50 characters after trimming spaces.

## Actual result

Accepted; reservation stored with a blank name.

## Evidence

Cycle 1 log: TC-EP-05 *Actual: Accepted (R1001, table T1)*.

## Root cause

Length was checked on the raw string; leading/trailing spaces were counted and never stripped.

## Fix

`name = str(name).strip()` before the length and pattern checks.  
File: `application/reservation_system/validators.py` · Fixed in build **v1.1.0** · Commit `f05852e`
