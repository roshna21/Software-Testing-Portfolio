## Steps to reproduce

1. Book 2 guests for **Friday 20 Nov 2026, 19:00**.
2. Check the deposit.

**Test data:** party 2, Fri 2026-11-20, 19:00

## Expected result

Deposit ₹0 (weekend means Saturday and Sunday only).

## Actual result

Deposit ₹300 – customer is over-charged.

## Evidence

Cycle 1 log: TC-DT-09 *Actual: Deposit Rs.300*.

## Root cause

`booking_date.weekday() >= 4` – Python numbers Monday as 0, so 4 is **Friday**. Weekend should be `>= 5`.

## Fix

Changed to `weekday() >= 5` and named it `SATURDAY` for readability.  
File: `application/reservation_system/service.py` · Fixed in build **v1.1.0** · Commit `9ea3267`
